# God's Pandora v0.3.0 — Every model. Every medium. One creative universe.

The first public release of **God's Pandora** (formerly God's Eye): a free, open-source desktop AI creative
studio where every tool runs on **your own cloud API keys** or **free open-source models on your GPU**.

## Highlights
- **Image, video, audio, 3D and live TouchDesigner visuals** in one app — 148 studio tools, 41 one-click apps.
- **Cloud + local, side by side** — FAL (985+ models), Replicate, OpenAI, Google, ElevenLabs, Stability,
  Hugging Face, Higgsfield, or SDXL / FLUX / Wan / Civitai LoRAs running offline. No credits, no markup.
- **Identity, Location and Product Lock** — the same face, place and product in every shot.
- **Shapeshift** (motion transfer / swap / restyle) and **Ad Multiplier** (rebuild a winning ad).
- **Pandora Models** — one search across Hugging Face, Civitai, OpenModelDB, Ollama and 185+ Pinokio apps
  (ACE-Step, YuE, Applio, F5-TTS, MMAudio…), plus 20+ model sites.
- **New look** — the living 3D Pandora box, colourful iOS-style interface, a unique cinematic scene behind
  every page, illustrated cards for every tool.

## Download
| Platform | File |
| --- | --- |
| Windows 10/11 (x64) | `Gods-Pandora-Setup-0.3.0.exe` |
| macOS (Apple Silicon / Intel) | `Gods-Pandora-0.3.0-arm64.dmg` / `-x64.dmg` |

> Windows may show "Windows protected your PC" until the installer is code-signed: click **More info → Run anyway**.
> macOS: run `xattr -cr "/Applications/God's Pandora.app"` once.

## Upgrading from God's Eye
Install over it — your API keys, library, characters, locations and local engine move over automatically.
