# Higgsfield — Research Summary (July 2026)

What Higgsfield is: a web/mobile "AI-native creative suite" that aggregates frontier image/video/audio models under one subscription, wrapped in director-grade controls and one-click apps.

## Product surface
- **Cinema Studio 3.5** — narrative video production. AI Director breaks a concept into shots; per-shot camera controls (dolly, truck, pan, tilt, crane, tracking, crash zoom); up to 3 stacked camera moves; collaborative editing.
- **Marketing Studio** — Seedance-2.0-powered; URL-to-video product ads in multiple formats.
- **Shorts Studio, Explainer** (topic → captioned video up to 10 min), **Canvas, AI Influencer Studio**.
- **Soul ID** — character consistency: trains an internalized identity from reference images (not single-image lookup), so the same face survives different models, scenes, lighting, angles. Multi Reference tool pins several visual anchors; Chrome Reference Extension.
- **Apps library (80+)** — Face Swap, Video Face Swap, Lipsync Studio, Headshot Generator, Skin Enhancer, Product Placement, Outfit Swap, Angles 2.0…
- **VFX presets** (explosions, transformations, transitions), Mixed Media (30+ stylized looks), viral presets (Bullet Time, 2000's Paparazzi, CGI Breakdown…).
- **Post tools** — brush inpainting (Edit Image), Edit Video, Topaz upscaling, background removal, color grade, expand.
- **Originals** — streaming section for long-form AI series (e.g. Zephyr).
- **Supercomputer + MCP/CLI** — agent layer that plans and executes multi-step creative jobs; app marketplace ($100K contest, July 2026).

## Model roster (rotating)
Seedance 2.0, Kling 3.0, Veo 3/3.1, Sora 2, Wan 2.6, MiniMax Hailuo 02, Flux Kontext, GPT Image, Seedream 5.0, Nano Banana Pro, Gemini Omni Flash, Seed Audio 1.0 — new frontier models added continuously.

## Pricing (2026 restructure)
Starter $15 / Plus $34 / Ultra $84 / Business $49-seat; ~200 / 1,000 / 3,000 monthly credits; unlimited generations on select models. Kling ≈ 6 credits per video; Sora 2 / Veo 3.1 ≈ 40–70. Top-ups ≈ $5 per 100 credits, expiring in ~90 days.

## The consistency gap God's Pandora exploits
Higgsfield locks **camera** (presets) and **character** (Soul ID) — but **not location**. Scenes drift between generations: the same "apartment" changes furniture, layout, and architecture shot-to-shot. God's Pandora adds **Location Lock**: saved virtual locations (multi-image reference + canonical description) applied to every generation the way Soul ID applies a face.
